1. 法体系と危険物の範囲

問題 1

指定数量未満の危険物の貯蔵・取扱いに関する規制として、正しいものはどれか。

  1. 国の法令（消防法等）による規制を受ける。
  2. 市町村条例による規制を受ける。
  3. 規制を受けることはない。
  4. 都道府県知事の許可が必要である。
答え・解説を表示
答え

2

解説

指定数量未満の危険物は、市町村条例（多くは火災予防条例）による規制を受けます。選択肢1は、指定数量以上の場合の規制であり誤りです。選択肢3は、規制が一切ないとしている点が誤りです。選択肢4は、都道府県知事の許可という制度自体が指定数量未満の規制内容と異なるため誤りです。

問題 2

消防法上の危険物の定義に関する記述として、正しいものはどれか。

  1. 消防法別表第一に掲げる物品で、定める性状を有するもの。
  2. 危険性が高いと一般に認識されているすべての物質。
  3. 高圧ガス保安法で定める高圧ガスを含む。
  4. 常温で気体、固体、液体のいずれの状態であってもよい。
答え・解説を表示
答え

1

解説

消防法上の危険物は、消防法別表第一に掲げる物品で、同表に定める性状を有するものに限られます。選択肢2は、法律上の定義ではなく一般的な危険性のイメージであり誤りです。選択肢3は、高圧ガスは別の法令（高圧ガス保安法）で規制されるため誤りです。選択肢4は、危険物は常温で固体または液体に限られ、気体は含まれないため誤りです。

問題 3

第1類及び第6類危険物に共通する性質として、正しいものはどれか。

  1. いずれも自身が燃える可燃性の物質である。
  2. いずれも自身は不燃であり、他の物質の燃焼を促進する酸化性の物質である。
  3. いずれも自然発火性と禁水性の両方の性質を持つ。
  4. いずれも常温で気体である。
答え・解説を表示
答え

2

解説

第1類（酸化性固体）と第6類（酸化性液体）は、いずれも自身は不燃で、他の可燃物の燃焼を著しく促進する酸化性の性質を持ちます。選択肢1は可燃性としており誤りです。選択肢3は第3類の性質と混同した誤りです。選択肢4は、危険物は気体ではないため誤りです。

問題 4

第2類、第4類、第5類に共通する性質として、正しいものはどれか。

  1. いずれも酸化性で、自身は燃えない。
  2. いずれも可燃性（自己反応性を含む）の性質を持つ。
  3. いずれも禁水性物質に分類される。
  4. いずれも常温で液体である。
答え・解説を表示
答え

2

解説

第2類（可燃性固体）、第4類（引火性液体）、第5類（自己反応性物質）は、いずれも可燃性（または自己反応性という形での可燃性）の性質を持つグループです。選択肢1は第1類・第6類の性質と混同した誤りです。選択肢3は第3類の一部の性質であり誤りです。選択肢4は、第2類・第5類には固体も含まれるため誤りです。

問題 5

消防法上の危険物の分類として、正しいものはどれか。

  1. 第１類は可燃性液体、第４類は酸化性固体である。
  2. 第４類は引火性液体であり、乙４の中心となる。
  3. 第５類は酸化性液体であり、水と反応して可燃性ガスを発生する。
  4. 危険物は性質に関係なく、すべて同じ類に分類される。
答え・解説を表示
答え

2

解説

第４類危険物は引火性液体です。乙４では第４類が中心ですが、第１類から第６類までの性質の違いも基本確認として問われます。

問題 6

第５類危険物の性質として、正しいものはどれか。

  1. 外部から酸素を供給しなければ燃焼しない。
  2. 物質自体に酸素を含み、自己燃焼するものがある。
  3. 水に触れると必ず可燃性ガスを発生する。
  4. すべて不燃性で、他物の燃焼を助けるだけである。
答え・解説を表示
答え

2

解説

第５類は自己反応性物質で、物質自体に酸素を含み、自己燃焼するものがあります。第１類・第６類の酸化性物質や、第３類の禁水性物質と区別します。

2. 第4類と指定数量

問題 7

第4類危険物に共通する性質として、誤っているものはどれか。

  1. 常温（20℃）で液体である。
  2. 蒸気は空気より重く、低所に滞留しやすい。
  3. 電気の良導体であり、静電気は蓄積しにくい。
  4. 燃焼範囲を持つ。
答え・解説を表示
答え

3

解説

第4類危険物は、多くが電気の不良導体であり、静電気が蓄積しやすい性質を持ちます。選択肢3はこの関係が逆であり誤りです。選択肢1・2・4は、いずれも第4類に共通する正しい性質です。

問題 8

水溶性と非水溶性の区別が指定数量及び消火方法に与える影響として、正しいものはどれか。

  1. 水溶性の危険物は、非水溶性のものより指定数量が小さい。
  2. 水溶性の危険物は、非水溶性のものより指定数量が大きく、また泡消火剤の選択に注意を要する。
  3. 水溶性・非水溶性の区別は、指定数量にのみ影響し、消火方法には影響しない。
  4. 水溶性・非水溶性の区別は、消火方法にのみ影響し、指定数量には影響しない。
答え・解説を表示
答え

2

解説

水溶性の危険物は、非水溶性のものに比べて指定数量が大きく設定されており（危険性がやや低いと評価される）、また消火の際には通常の泡消火剤が溶解（破壊）されやすいため、耐アルコール泡等の選択に注意が必要です。選択肢1は大小関係が逆であり誤りです。選択肢3・4は、いずれか一方のみに影響するとしており誤りです（両方に影響します）。

問題 9

第4類危険物のアルコール類の除外規定に関する記述として、正しいものはどれか。

  1. 水溶液中のアルコール濃度が60％未満のものは、アルコール類から除外される場合がある。
  2. アルコール類には除外規定が一切存在しない。
  3. 炭素原子数が4個以上のアルコールも、すべてアルコール類に含まれる。
  4. メタノールとエタノールのみが除外規定の対象である。
答え・解説を表示
答え

1

解説

1分子を構成する炭素原子数が1〜3個の飽和1価アルコールのうち、水溶液中のアルコール濃度が60％未満のもの等は、総務省令により除外される場合があります。選択肢2は除外規定がないとしており誤りです。選択肢3は、炭素原子数4個以上のものはそもそもアルコール類の定義（1〜3個）に当てはまらないため誤りです。選択肢4は除外規定の対象を物品名で限定しており、実際は濃度等の条件によるものであるため誤りです。

問題 10

指定数量の倍数の計算に関する記述として、正しいものはどれか。

  1. 複数の危険物を貯蔵する場合、最も指定数量の小さい危険物のみで判断する。
  2. 複数の危険物を貯蔵する場合、各危険物の倍数を合計して判断する。
  3. 指定数量の倍数は、常に整数になるよう計算方法が定められている。
  4. 指定数量の倍数は、危険物の種類によらず一律の方法で計算できない。
答え・解説を表示
答え

2

解説

複数の危険物を同一場所で貯蔵・取扱いする場合、各危険物の指定数量の倍数をそれぞれ計算し、その合計で判断します。選択肢1は、最も小さい危険物のみで判断するとしており誤りです。選択肢3は、倍数は小数になることもあるため誤りです。選択肢4は、計算方法自体は「数量÷指定数量」という共通の式で計算できるため誤りです。

問題 11

灯油500Lと軽油500Lを同一の場所で貯蔵している場合の指定数量の倍数として、正しいものはどれか。

  1. 5倍
  2. 0倍
  3. 5倍
  4. 0倍
答え・解説を表示
答え

2

解説

灯油の倍数は 500L ÷ 1,000L ＝ 0.5、軽油の倍数も 500L ÷ 1,000L ＝ 0.5 です。これらを合計すると、0.5 ＋ 0.5 ＝ 1.0倍となります。選択肢1はどちらか一方の倍数のみで判断した誤り、選択肢3・4は計算を誤ったものです。

問題 12

第4類危険物のうち、指定数量が最も小さい品名として、正しいものはどれか。

  1. アルコール類
  2. 第1石油類（非水溶性）
  3. 特殊引火物
  4. 第2石油類（非水溶性）
答え・解説を表示
答え

3

解説

特殊引火物の指定数量は50Lで、第4類の中で最も小さく、最も危険性が高い品名とされています。選択肢1（アルコール類：400L）、選択肢2（第1石油類・非水溶性：200L）、選択肢4（第2石油類・非水溶性：1,000L）は、いずれも特殊引火物より指定数量が大きいため誤りです。

問題 13

次の危険物を同一の場所で貯蔵する場合、指定数量の倍数の合計として正しいものはどれか。二硫化炭素（特殊引火物）25L、アセトン（第1石油類・水溶性）200L、メタノール（アルコール類）200L。

  1. 0倍
  2. 5倍
  3. 0倍
  4. 5倍
答え・解説を表示
答え

2

解説

特殊引火物の倍数は 25L ÷ 50L ＝ 0.5。アセトン（第1石油類・水溶性、指定数量400L）の倍数は 200L ÷ 400L ＝ 0.5。メタノール（アルコール類、指定数量400L）の倍数は 200L ÷ 400L ＝ 0.5。合計すると 0.5 ＋ 0.5 ＋ 0.5 ＝ 1.5倍となります。選択肢1・3・4は、いずれかの危険物の倍数計算を誤った場合に生じやすい誤答です。

※このように、3種類以上の危険物が混在する計算問題も出題されます。1つずつ丁寧に倍数を計算し、最後に合計する手順を徹底しましょう。

3. 製造所等の区分と主な設備基準

問題 14

貯蔵所に分類される施設として、誤っているものはどれか（＝貯蔵所に該当しないものを選べ）。

  1. 屋内貯蔵所
  2. 簡易タンク貯蔵所
  3. 一般取扱所
  4. 移動タンク貯蔵所
答え・解説を表示
答え

3

解説

一般取扱所は「取扱所」に分類される施設であり、「貯蔵所」には該当しません。選択肢1（屋内貯蔵所）、選択肢2（簡易タンク貯蔵所）、選択肢4（移動タンク貯蔵所）は、いずれも貯蔵所の7種類に含まれる施設です。

問題 15

取扱所に分類される施設の組み合わせとして、正しいものはどれか。

  1. 給油取扱所、販売取扱所、移送取扱所、一般取扱所
  2. 給油取扱所、屋内貯蔵所、移送取扱所、一般取扱所
  3. 販売取扱所、屋外タンク貯蔵所、移送取扱所、一般取扱所
  4. 給油取扱所、販売取扱所、簡易タンク貯蔵所、一般取扱所
答え・解説を表示
答え

1

解説

取扱所に分類される施設は「給油取扱所・販売取扱所・移送取扱所・一般取扱所」の4種類です。選択肢2・3・4は、いずれも貯蔵所（屋内貯蔵所、屋外タンク貯蔵所、簡易タンク貯蔵所）を取扱所として誤って含んでいます。

問題 16

ガソリンスタンドに該当する施設の名称として、正しいものはどれか。

  1. 販売取扱所
  2. 給油取扱所
  3. 一般取扱所
  4. 屋外貯蔵所
答え・解説を表示
答え

2

解説

ガソリンスタンドは、固定した給油設備によって自動車等に直接給油する施設であり、「給油取扱所」に該当します。選択肢1（販売取扱所）は、店舗で容器入りの危険物を販売する施設であり異なります。選択肢3（一般取扱所）、選択肢4（屋外貯蔵所）も、それぞれ異なる用途の施設であるため誤りです。

問題 17

屋外タンク貯蔵所のタンクに関する基準として、正しいものはどれか。

  1. タンクは木製で造ることができる。
  2. タンクは原則として鋼板で造り、十分な強度を有すること。
  3. 水圧試験は不要である。
  4. 通気管や安全装置の設置は不要である。
答え・解説を表示
答え

2

解説

屋外タンク貯蔵所のタンクは、原則として鋼板で造り、十分な強度を有することが基準です。選択肢1は木製を認めており誤りです。選択肢3は、最大常用圧力の1.5倍の圧力で10分間行う水圧試験等が必要であるため誤りです。選択肢4は、圧力タンク以外には通気管、圧力タンクには安全装置の設置が必要であるため誤りです。

問題 18

屋外タンク貯蔵所の防油堤に複数のタンクを設置する場合の容量の基準として、正しいものはどれか。

  1. すべてのタンクの容量の合計の110％以上とする。
  2. 最大のタンクの容量の110％以上とする。
  3. 最大のタンクの容量の100％とすればよい。
  4. 防油堤の容量に関する基準は存在しない。
答え・解説を表示
答え

2

解説

防油堤内に複数のタンクがある場合、防油堤の容量は最大のタンクの容量の110％以上とすることが基準です（すべてのタンクの合計ではない点に注意）。選択肢1は合計を基準としており誤りです。選択肢3は割合が誤りです。選択肢4は基準が存在しないとしており誤りです。

問題 19

移動貯蔵タンクの間仕切りに関する基準として、正しいものはどれか。

  1. 2,000Lごとに間仕切りを設ける。
  2. 4,000Lごとに間仕切りを設ける。
  3. 間仕切りの設置義務はない。
  4. 間仕切りで仕切られた部分の容量が1,000Lを超える場合、防波板を設ける。
答え・解説を表示
答え

2

解説

移動貯蔵タンクは、内部に4,000Lごとに間仕切りを設けることが基準です。選択肢1は数値が誤りです。選択肢3は設置義務がないとしており誤りです。選択肢4は、防波板が必要となる容量の基準が誤りです（正しくは2,000L超）。

問題 20

移動タンク貯蔵所に乗車する者に関する基準として、正しいものはどれか。

  1. 危険物取扱者である必要はなく、運転免許があればよい。
  2. 当該タンクで貯蔵・取扱う危険物を取り扱うことができる危険物取扱者が乗車しなければならない。
  3. 危険物取扱者は同乗するが、免状の携帯は不要である。
  4. 複数人が乗車する場合、誰か一人が無資格者でもよい。
答え・解説を表示
答え

2

解説

移動タンク貯蔵所には、当該タンクで貯蔵・取扱う危険物を取り扱うことができる危険物取扱者が乗車しなければなりません。選択肢1は資格が不要としており誤りです。選択肢3は、危険物取扱者は免状を携帯していなければならないため誤りです。選択肢4は、危険物取扱者自身が乗車している必要があるため誤りです（無資格者のみが乗車する状態は認められません）。

問題 21

移動タンク貯蔵所の標識に関する基準として、正しいものはどれか。

  1. 地は白色、文字は黒色とする。
  2. 地は黒色、文字は黄色の反射塗料等とする。
  3. 標識の設置は任意である。
  4. 標識の大きさに規定はない。
答え・解説を表示
答え

2

解説

移動タンク貯蔵所の「危」の標識は、地が黒色、文字が黄色の反射塗料等とする点が特徴です（通常の標識・掲示板の地白・文字黒とは異なる例外）。選択肢1は通常の標識の色であり誤りです。選択肢3は設置が任意としており誤りです。選択肢4は、大きさは0.3m平方以上0.4m平方以下と規定されているため誤りです。

問題 22

給油取扱所の給油空地に関する基準として、正しいものはどれか（おおむねの目安）。

  1. 幅5m以上、奥行3m以上
  2. 幅10m以上、奥行6m以上
  3. 幅20m以上、奥行10m以上
  4. 給油空地の大きさに関する基準は存在しない
答え・解説を表示
答え

2

解説

給油空地は、おおむね幅10m以上、奥行6m以上を確保することが基準です。選択肢1は数値が小さすぎ、選択肢3は数値が大きすぎるため誤りです。選択肢4は基準が存在しないとしており誤りです。

問題 23

給油取扱所の周囲に設ける塀又は壁に関する基準として、正しいものはどれか。

  1. 高さ1m以上の不燃材料の塀又は壁を設ける。
  2. 高さ2m以上の耐火構造又は不燃材料の塀又は壁を設ける。
  3. 塀又は壁の設置は任意である。
  4. ガラス製の塀であれば設置基準を満たす。
答え・解説を表示
答え
